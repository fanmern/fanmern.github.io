怎么用

  1. 在日常 Chrome 里打开一次，记下结果作为基线。
  2. 再用专用 profile 的 Chrome（带 --user-data-dir 启动的那个）打开一次。
  3. 对比两次结果：重点关注「webdriver」「自动化全局变量」「插件数量」是否出现差异，这几项是硬信号。
  4. Canvas / Audio / WebGL 的指纹哈希在不同 profile 之间本来就会不同，这是身份隔离的预期结果，不是被识别。

小提示：双击打开时地址栏是 file://，通知权限状态不具参考性，本页会自动标注。 想要更真实的环境，可在本目录执行 python3 -m http.server 8899 后访问 http://127.0.0.1:8899/。
